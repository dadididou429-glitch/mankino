# Mankino AI — سريع + قوي

توليد صور وفيديوهات أزياء عبر Google Gemini API الرسمي (Google AI Studio).

## التحسينات

- الافتراضي: **Nano Banana 2** (أسرع)
- خيار **Nano Banana Pro** للجودة الأعلى
- ضغط الصورة قبل الإرسال لتسريع الرفع
- 1K للسرعة / 2K لـ Pro

## النشر

### Backend (Render)
1. Root Directory = `backend`
2. `GEMINI_API_KEY` في Environment Variables

### Frontend (GitHub Pages)
ارفع الملفات من الجذر: `index.html`, `app.js`, `style.css`, `manifest.json`
