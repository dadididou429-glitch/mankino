# مانكينو — Mankino

واجهة أولية لتطبيق Android/Web مخصص لمتاجر الملابس وعرّضي الأزياء بالذكاء الاصطناعي.

## الملفات
- `index.html` — الواجهة الرئيسية
- `style.css` — التصميم
- `app.js` — التفاعل واختيار الصور والنمط
- `manifest.json` — إعدادات PWA
- `sw.js` — دعم العمل كـ PWA
- `README.md` — هذا الملف

## التشغيل
يمكن رفع الملفات مباشرة إلى GitHub Pages.

## المرحلة التالية
الواجهة الحالية لا تستدعي نموذج توليد حقيقي بعد. الخطوة التالية هي ربط:
- توليد الصور
- Image-to-Video
- رفع الصور
- حسابات المستخدمين
- حفظ النتائج

ملاحظة: لا يتم تجاوز تسجيل الدخول أو حماية أي خدمة خارجية. الربط النهائي يجب أن يستخدم API رسميًا ومسموحًا به من مزود النموذج.
