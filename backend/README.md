# Mankino AI Backend

## النماذج

- **Nano Banana 2 (سريع):** `gemini-3.1-flash-image`
- **Nano Banana Pro (أقوى):** `gemini-3-pro-image`
- **Veo 3.1:** `veo-3.1-generate-preview`
- **Gemini Omni Flash:** `gemini-omni-1.1-flash`

## Render

- Root Directory: `backend`
- Build: `npm install`
- Start: `npm start`
- Environment Variable: `GEMINI_API_KEY`

لا تضع المفتاح في الكود أو GitHub.
